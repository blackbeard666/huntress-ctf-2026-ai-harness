# mobile-android: coverage atlas (D1-D26 seen, D27+ forecast)

Scope: common Android/mobile CTF concepts mapped against what this lane has shipped and what the harness can handle.
Ground truth (see `reference/techniques/mobile-android.md`): all 25 days shipped the same ~12.7 KB fixture. The day's
THEME was flavour only (manifest `huntress.mechanic` + dex `DAY-NN:<theme>:<mechanic>`). The answer `ANS-<16 HEX>` was
in `assets/huntress_puzzle.json` behind a rotating codec (plain/reverse/base64/xor/split/hex/caesar/native/indexed/
reflection) on D1-D19. D15
added the first real extra payload (`lib/x86_64/libarena.so` with the answer as a `.rodata` literal) and mixed-day
Mastery. D16 (JNI Boundary) TT/Mastery builds added the first REAL gate in code: `Java_<pkg>_JNIBoundary_nativeEvidence(int
len)` returns `arena_value` only if `len > 0xffff && (u16)len == 0` -- still with the literal in the asset and `.rodata`.
D17 (Name Collapse, R8-style identifier collapse) left the native track: 6-entry fixture, new per-char permutation codec
`indexed`, one renamed class `a`; the TT dex carried the real hint `follow b -> a and ignore field c` + `decoy` strings.
D18 (Encrypted Strings, `string_decryption` "runtime string decryption"): 6-entry fixture, codec `xor` again (b64 + 1-byte
key); single dex had no cipher code, the TT/Mastery dex added class `EncryptedStrings` method `decryptByte` + `STRUCTURAL`.
D19 (Reflection Maze, `reflective_dispatch` "reflective secret dispatch"; prompt "Reconstruct reflective dispatch across
generated equivalent call graphs"): 6-entry fixture, NEW codec name `reflection` whose `data` is the plaintext answer;
class `ReflectionMaze`, but NO reflection API in any dex; TT/Mastery dex only added `dispatch` + `STRUCTURAL` strings.
D20 (Loaded Later, `dynamic_dex` "secondary DEX loading"; prompt "Analyze a challenge-signed secondary DEX and recover
the module contract"): 7-entry APK with `assets/payload.dex` (508 B, plain dex 035); NEW codec `dynamic` whose `data` is
the ENTRY PATH `assets/payload.dex` -- the FIRST day the answer left the JSON value: a plain `ANS-` const in payload class
`com.huntress.arena.payload.Module` (strings `ANSWER`, `CONTRACT`, `DAY20-SIGNED-MODULE:..`). No ClassLoader/verify code
in any host dex; TT/Mastery host dex added `moduleContract` + `assets/payload.dex:com.huntress.arena.payload.Module`.
D21 (Debug Me If You Can, `anti_debug` "anti-debug state checks"; prompt "Neutralize a clean-room anti-debug state machine
while retaining the intended app flow"): plain 6-entry fixture, codec back to `reverse` (d2/d8) -- the D20 pointer did
NOT persist. First manifest with `android:debuggable="true"` (single/TT/Mastery-d21 only). No debugger/TracerPid/clock
API and no state loop in any dex; TT/Mastery dex only added `debuggerGate` + `STRUCTURAL`.
D22 (Root of Trust, `root_detection` "synthetic root detection"; prompt "Model and bypass multiple synthetic root signals
without globally patching success"): plain 6-entry fixture, codec `base64` (4th time), debuggable false again. No root
probe API (File/Build/Runtime.exec/su/magisk) in any dex; TT/Mastery dex only added `rootSignals` + `STRUCTURAL`.
FIRST 6-set Mastery (d01 plain, d07 caesar, d12 hex, d13 base64, d17 indexed, d22 base64).
D23 (Hook Line and Signal, `hook_detection` "hook and instrumentation detection"; prompt "Separate real instrumentation
signals from generated false positives"): single = v1 `xor` (key 81). **TT and all 7 Mastery sets (d02, d06, d10, d14,
d15, d22, d23 -- old days REGENERATED) shipped puzzle schema v2 `{"codec":"analysis","build":..}` with NO data: the answer
is COMPUTED by dex code** -- `Release.code(Context)` = `"ANS-"` + 16 hex nibbles of a static 64-bit mixer chain
(`token()` = mixA(scanB(mixC(seed))); `scan*` folds in `Probe.s1/s2/s3` 12-bit inverse searches and a theme gate fn such
as `instrumentationSignals = (a^b^c)&7`; d14 set adds an LCG `long[16]` table walk; d15 set calls JNI `nativeShare(long)`
in `libarena.so`). Unreferenced look-alike mixers/`K*` consts = the "generated false positives". Solved by jadx +
javac-with-Context-stub (LLM worker); the solver had no v2 path and `bytecode_vm_scan` resolved 2 of 8 v2 APKs.
D24 (Emulator Alibi, `emulator_detection` "emulator environment detection"; prompt "Defeat app-owned environment checks on
the same pinned emulator used by the solve oracle"): single = v1 `split` (`parts[3]` + `order [2,0,1]`). TT + FIRST 8-set
Mastery (d03, d06, d09, d10, d15, d17, d23, d24) all v2 `analysis`, same shape as D23: theme = gate fn
`EmulatorAlibi.emulatorScore(a,b,c) = (a+b+c)%4` over `Probe.s*` ints, decoys `sealEmu*`/`KQemu*`; NO Build/qemu/sensor/
telephony API in any dex. The overnight v2 evaluator (lib deep Dalvik eval + solve.py unicorn JNI hop) solved all three
modes first try (single 16.3 s via race probe, TT 2.5 s, Mastery 3.1 s).
D25 (Integrity Signals, `integrity_signal` "challenge-owned integrity statement"; prompt "Forge or replay a bounded
challenge-owned integrity statement and explain the missing binding" -- Play Integrity nonce/requestHash pun): single =
v1 `hex`. TT = v2 with gate `IntegritySignals.integrityStatement(long,int) = a ^ (long)b` (first `(JI)J` gate; only 2
probe calls), classes `SealCheck`/`VerdictMap`, decoys `KSeal*`/`KStatement*`/`KCert*`; NO PackageManager/signature/
IntegrityManager/token code. FIRST 9-set Mastery (d01, d04, d07, d10, d14, d16, d19, d22, d25), all v2, and the old-day
sets now carry their REAL mechanic: d19 set = `Class.forName`/`getDeclaredMethod`/`Method.invoke` dispatch picking 1 of
8 `Maze.mN(long)` via a packed-switch `dispatch(int)`; d16 set = `native nativeShare(long,int)` with the u16
length-narrowing gate in the export. Solver 3/3 first try (single ~5 s race probe, TT 2.2 s, Mastery 3.7 s; Mastery solve
1.89 s, double D24's).
D26 (Split Decision, `split_apk` "base and feature split correlation"; prompt "Reassemble evidence distributed across base
and configuration splits"): FIRST non-APK container in all modes -- `*.apks` = stored zip of `base.apk` + `feature.apk`
(manifest `split="arena_feature"`, `hasCode=false`, one asset). Single v1: base `split` puzzle with an EMPTY `parts` slot
filled from the feature's `huntress_feature.json` `{part, part_index}`, then `r[order[i]]=parts[i]`. TT + Mastery set10
v2: gate `SplitDecision.splitIndex(a,b)=(a<<4)|b`, and the FIRST chain that READS ARTIFACT BYTES: `Assets.readSplit
("huntress_feature.bin")` walks `getApplicationInfo().splitSourceDirs` with `java.util.zip.ZipFile`, reads 16 B, folds
two big-endian u64 into the token. The deep evaluator aborted (no split bytes) -> solver silent in TT and on set10; live
workers hand-solved (TT 83 s, Mastery 88 s). 10-set Mastery: old-day d11/d13/d21 first time as v2, pure chains.
So "seen Dn" below means the THEME was named that day; through D22 no exploit was ever needed. D23-D24 TT/Mastery
compute the answer in code: assume the timed builds evaluate code, and that tomorrow's theme becomes a gate
fn / probe set INSIDE the v2 chain (the d10/d14/d22 sets already carry `gateDomain*`/`gateStream*` theme fns).
D15-D22 read as a MASVS-RESILIENCE / obfuscation arc (native secret -> JNI gate -> name obfuscation + decoys -> string
encryption -> reflection -> dynamic code loading -> anti-debug -> root detection -> hook (D23) -> emulator (D24) -> Play Integrity verdict (D25)).
Still unnamed in that arc: tamper/repackaging/installer, key attestation (D22's title pun is
the attestation `RootOfTrust` ASN.1 record), certificate pinning checks, then obfuscation capstones (flattening, VM, white-box crypto). After it the untouched MASVS
groups are AUTH (biometric/local auth) and the leftover IPC surfaces (bound Service/AIDL, broadcast receivers).
Next expect also: the payload ENCRYPTED/wrapped (key in host dex, unwrap by
magic known plaintext), "challenge-signed" made real (several payloads, only the one whose digest/signature matches a
pinned value is loaded), >1 `ANS-` in the payload with the host-named member (`moduleContract`) deciding, class shadowing
between host and payload loaders, multi-stage loaders, anti-tamper / root / emulator / debugger / Frida checks, and
control-flow flattening or a tiny VM. New codecs keep arriving (d7 caesar, d15 native, d17 indexed, d19 reflection, d20
dynamic) and old ones recur (d18 xor, d21 reverse): check `data` for `ANS-`, then for an entry name, then decode from `ANS-` alone.
