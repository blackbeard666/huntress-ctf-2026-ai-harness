# Warmups coverage atlas

Lane: one `message` question over `blob.txt`. Plaintext is ALWAYS the fixed sentence
`Nice work decoding this warmup! To solve, submit this exact answer to the Game Master: <adj>-<noun>-<noun>-NN`
(87 chars + slug, ~105-115 bytes). One new keyless codec per day, named by a pun in the title; Mastery line k = day k's
codec over a mid-word fragment (`NN<TAB>fragment`). D16-D17 were STACKED: a symbol carrier over HEX (D16 Morse, D17
Baconian a/b 5-groups whose values 0-15 are the nibbles), both cued by "Sixteen". D18 went back to ONE layer and opened
a new family, TRANSPOSITION: rail fence, 3 rails, offset 0 ("Three rails. One very zigzag commute." / "Off the Rails");
the prompt's number was the key. D19 ("Two bytes walk into a bar. The little one goes first." / "Little Things") was
HEX of the UTF-16LE bytes with a `fffe` BOM: two layers again, the inner one a TEXT ENCODING (byte representation), the
pun naming code-unit width ("two bytes") and byte order ("little ... first"). D20 ("Same bar. This time the big one goes
first." / "Big Entrance") was the SAME codec with ONE knob turned: hex of UTF-16BE with a `feff` BOM -- a callback pun
("Same bar") plus the changed parameter ("big"); the BOM-aware D19 solver passed it unchanged. Expect more "same X,
one knob" days: the third byte order (middle/PDP-endian), four bytes (UTF-32, prebuilt), no BOM (prebuilt), the whole
text as one BIG integer, or a knob on an older day's codec (code-unit escapes byte-swapped, bit order, alphabet).
D21 ("A familiar wrapper. Something compressed inside." / "Under Pressure") opened a new family, COMPRESSION: GZIP
inside standard padded BASE64 (`H4sIAAAAAAACA...`, header `1f8b0800 00000000 0203`); Mastery line 21 = each 36-char
fragment its own gzip member. "Familiar wrapper" = an already-seen codec as the OUTER layer. Expect the D19->D20
pattern again ("same wrapper, other squeeze") -- and D22 delivered it: "Another familiar wrapper. This one needs a little
inflation." / "Deflated Ego" = ZLIB (`78da`, level 9) inside std padded BASE64 (`eNo..`/`eNp..`/`eNr..`); Mastery line
22 = each 20-char fragment its own zlib stream. The D21 solver's `_b64z` (magic sniff incl. `\x78`) passed it unchanged.
RHYTHM since D19: day N opens a family, day N+1 turns ONE knob (D19 LE -> D20 BE, D21 gzip -> D22 zlib). D23-D25 each
opened a NEW family instead: D23 "The alphabet got bigger. Adobe might recognize the neighbors." = ASCII85 `<~...~>`
(Mastery line 23 own delimiters); D24 "Count carefully. The comma knows where to stop." / "String Theory" = DJB
NETSTRINGS `1:N,1:i,...` (one char per frame, payload `,`/`:` framed as `1:,,`/`1::,`; line 24 `1:o,1:n,...`); D25
"Every character has a point. A code point, anyway." / "You Have a Point" = Unicode CODE POINTS `U+004E U+0069 ...`
(UPPERCASE, 4 hex digits, single spaces, 762 B = 7 B per char; Mastery line 25 = 5 tokens per fragment), one layer,
plain text inside -- a return to the D7-D9 CHARACTER-NOTATION family (D9 was `"\u00XX"`), predicted here as row 22
(prebuilt `uplus_dec`, single CORRECT ~27 s). Only a "Same ..."/"Another ..." prompt has signalled a knob day.
D26 ("A very small language has quite a lot to say." / "Food for Thought" = brain food) opened a NEW family,
ESOTERIC LANGUAGES: a BRAINFUCK program whose output is the sentence -- only `+ - .`, one cell, each char = a run of one
sign equal to the delta from the previous char, then `.` (3406 B, ~31 B per char; Mastery line 26 = the same over a
5-char tail, 166-217 B). Row 83 had rated it LOW ("program, not encoding"): the pun named a LANGUAGE, not a codec. The
Unicode/notation queue (rows 173-182, all built) did not come. Mastery broke on it: the solver's runtime DAYS encoder
(absolute `+`*ord) did not round-trip the GM's delta bytes -> 64.9 s timeout (see mastery-line-routing).
D27 ("Ook. Ook? Ook! Someone seems chatty." / "Monkey Business") was the BF KNOB predicted here, (a) first: OOK!, the
exact D26 one-cell delta program re-spelled as `Ook.`/`Ook!` word PAIRS (single-spaced, no `Ook?` used, ~314 B per
char, 33929 B; Mastery line 27 = 1672-2172 B printing a 4-5 char tail). A knob day WITHOUT a "Same"/"Another" cue:
the prompt quoted the dialect's tokens. Prebuilt `warmups_codecs.bfd_dec` (row 183) covered it; single CORRECT ~33 s,
TT/Mastery first try (Mastery solve 34.9 s: the solver's own DAYS[27] encoder again was not GM-faithful).
D28+ forecast, in order: (a) a THIRD esolang day -- another spelling or another tiny language: unknown word triads /
unseparated or emoji token maps (row 194), animal-word languages (Chicken, row 193 -- "monkey" -> next animal),
Brain-Flak (`()[]{}<>`, row 192), bit-level BF (Boolfuck, row 197), prefix-code Spoon (row 195), the built esolang rows
184-191 (Deadfish, Whitespace, Befunge, JSFuck, Chef, stack VM, Malbolge); (b) a program whose OUTPUT is itself a seen
codec, or a program under a seen wrapper (row 196: always re-decode interpreter output); (c) a new family for the
last days (D28-D31). All keyless and RUNNABLE: pure-python, step-capped interpreters + crib slug gate. Snapshot
2026-10-27 (after D27; every earlier prebuild gap is built; new queue rows 192-200).

Status legend: `seen Dn` = GM-confirmed day codec (`lib.warmups_codecs.DAYS`, `lib.decode.decode_chunk`/`FREE_CODECS`).
`prebuilt tgt:<id>` = speculative race module + fixtures from `tests/data/warmups_fixtures/TARGETS.json` (KEPT in
`.run/prebuild-state.json`). `prebuilt wc:<name>` = encoder/decoder pair in `lib.warmups_codecs.CANDIDATES` (used by
`infer`/`plaintext`/today-probe; free-text ones also `SPECULATIVE_FREE`). `prebuilt dec:<fn>` = `lib.decode` branch.
`gap` = nothing in lib (a standard tool may still decode it: chepy 7.x and CyberChef at `tools/npm-cyberchef` are
installed; `.venv` has `base58`, `pycipher`, `Crypto`; NOT installed: base45/base91/pybase62/pybase100/z85/unidecode).

**Crib fact (all keyed rows):** the first 87 plaintext chars are known, so ANY fixed-key letter cipher leaks its key
from the blob alone: Vigenere/Beaufort/Gronsfeld/autokey key = (c - p) / (p - c) / (k - c) over the crib, period =
smallest repeat; keyword substitution = the crib map (21 of 26 letters; only f j q y z unseen, slug-only).
"Keyless?" below therefore means "decodable without outside info": title pun OR crib.
